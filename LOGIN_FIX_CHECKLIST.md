# تحقق من سبب عدم عمل تسجيل الدخول

اتبع الخطوات بالترتيب واكتب نتيجة كل خطوة.

---

## 1) هل الباكند (Node) يعمل على الرابط؟

افتح في المتصفح:

**https://palmaa.onrender.com/api/auth/ping**

- إذا ظهر: `{"ok":true,"api":"auth","message":"Backend is Node.js"}`  
  → الباكند شغال على هذا الرابط. انتقل للخطوة 2.

- إذا ظهر **404** أو صفحة أخرى:  
  → الرابط هذا **ليس** الباكند (غالباً سيرفر ستاتيك).  
  **الحل:** عندك خياران:
  - إما تنشر الباكند كـ **Web Service** على Render (Root Directory: `server`، Start: `node server.js`) وتستخدم الرابط اللي يعطيك Render للباكند.
  - أو إذا الباكند على رابط ثاني (مثلاً `https://palma-api.onrender.com`)، لازم تبني الفرونت مع هذا الرابط:
    - `VITE_API_URL=https://الرابط-الحقيقي-للباكند`
    - `npm run build`
    - ثم ارفع محتويات مجلد `dist` من جديد.

---

## 2) متغيرات البيئة على Render

في Render → مشروع الباكند → **Environment**:

| المتغير                                               | المطلوب                                                            |
| ----------------------------------------------------- | ------------------------------------------------------------------ |
| `SUPABASE_URL`                                        | رابط مشروعك من Supabase (Dashboard → Settings → API → Project URL) |
| `SUPABASE_SERVICE_KEY` أو `SUPABASE_SERVICE_ROLE_KEY` | **المفتاح السري** (Service role) من نفس الصفحة، **ليس** anon key   |

لو استخدمت anon key بالغلط، الداتا (مثل عمود كلمة المرور) قد لا تُرجع بشكل صحيح.

---

## 3) جدول المستخدمين في Supabase

- ادخل **Supabase** → **Table Editor** → جدول **users**.
- تأكد أن فيه عمود اسمه **password** (بحروف صغيرة).
- افتح أي مستخدم مسجّل حديثاً: عمود **password** يجب أن يكون **غير فارغ** والقيمة تبدأ بـ **$2a$** أو **$2b$**.

إذا العمود غير موجود أو القيم فاضية، شغّل سكربت **supabase/setup.sql** من أوله في **SQL Editor** ثم أعد المحاولة.

---

## 4) ماذا يطبع الباكند عند محاولة الدخول؟

بعد ما تجرب تسجيل الدخول (بريد + كلمة مرور):

- ادخل **Render** → مشروع الباكند → **Logs**.
- ابحث عن سطر يبدأ بـ `[authService] login:`

ستجد أحد هذه:

| الرسالة                                                         | المعنى                                                                                                                                            |
| --------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `login: no user found for email`                                | لا يوجد مستخدم بهذا البريد. تأكد من البريد أو سجّل مستخدم جديد.                                                                                   |
| `login: user found` ثم `hasPassword: false` أو `passwordLen: 0` | المستخدم موجود لكن عمود كلمة المرور فاضي أو غير مرجع من Supabase. راجع الخطوة 2 و 3.                                                              |
| `login: bcrypt compare failed`                                  | المستخدم موجود وكلمة المرور موجودة في DB لكن المدخل لا يطابقها. تأكد من كتابة كلمة المرور نفسها (بدون مسافات زائدة، وحروف كبيرة/صغيرة كما سجّلت). |

انسخ السطر من الـ Logs وأرسله إذا حاب نحدد السبب بالضبط.

---

## 5) تجربة استعادة كلمة المرور

من واجهة الموقع:

1. اضغط **نسيت كلمة المرور**.
2. أدخل **نفس البريد** اللي تحاول تدخل فيه.
3. استلم الرمز (من البريد أو من الـ Logs إذا البريد غير مضبوط).
4. ضع كلمة مرور جديدة ثم احفظ.
5. جرّب تسجيل الدخول بالبريد + كلمة المرور الجديدة.

إذا الدخول اشتغل بعد هالخطوة، معناها الحساب كان موجود لكن كلمة المرور القديمة كانت غير مخزنة أو غير صحيحة.
