## مطابقة الكود مع التوثيق المُتحقق منه

| البند                    | التوثيق                                                                                                                                      | المشروع                                                                                                     | الحالة |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- | ------ |
| endpoint الدفع (Test)    | testsecureacceptance.cybersource.com/pay                                                                                                     | `CYBS_HOSTED_PAY_URL` افتراضي نفس الرابط                                                                    | ✅     |
| التوقيع                  | HMAC-SHA256، Secret Key، signed_field_names                                                                                                  | `cybersource.signature.js`: createHmac('sha256', secretKey), buildStringToSign حسب ترتيب signed_field_names | ✅     |
| التحقق من الاستجابة      | مقارنة التوقيع على السيرفر                                                                                                                   | verifySignature + timingSafeEqual في handleNotification                                                     | ✅     |
| الحقول الموقّعة المطلوبة | access_key, amount, currency, locale, profile_id, reference_number, signed_date_time, signed_field_names, transaction_type, transaction_uuid | كلها مرسلة + اختياري outlet/terminal                                                                        | ✅     |
| transaction_type         | sale (دفع فوري)                                                                                                                              | `transaction_type: 'sale'`                                                                                  | ✅     |
| locale عربي              | ar-xn                                                                                                                                        | `CYBS_LOCALE` افتراضي 'ar-xn'                                                                               | ✅     |
| إشعار التاجر             | Merchant POST URL يستقبل decision + signed response                                                                                          | POST /api/payments/cybersource/notify، urlencoded، verifySignature ثم handlePaymentCallback                 | ✅     |
| بطاقات الاختبار          | Visa 4111111111111111، إزالة المسافات                                                                                                        | البطاقات من دليل الاختبار؛ المشروع لا يرسل البطاقة (Hosted يدخلها الزبون)                                   | ✅     |

## ملاحظات التحقق

1. **صفحة Required Signed Fields:** مذكورة داخل [Payment Transactions](https://developer.cybersource.com/docs/cybs/en-us/sa/developer/all/sa-hosted/secure-acceptance/sa-payment-txns.html) وليس لها رابط مستقل بنفس الاسم؛ المحتوى ضمن sa-payment-txns.
2. **بعض الصفحات:** قد تعطي timeout عند التحميل المباشر (مثل Payment Transactions، Reason Codes، Customer Response Page)؛ الروابط صحيحة ويمكن فتحها من المتصفح.
3. **Testing Credit Card Services:** الرابط من Test and View Transactions يؤدي لصفحة Simple Order API Test Data؛ نفس أرقام البطاقات تستخدم في Hosted Checkout (Visa 4111 1111 1111 1111، إلخ).
4. **Profile Test vs Production:** لا يمكن نسخ البروفايل من Test إلى Production؛ يجب إنشاء بروفايل جديد في Production وإعادة الإعدادات والمفاتيح.

## خلاصة

- **الروابط الرئيسية** في القائمة الجانبية للتوثيق كلها تحت نفس المسار `docs/cybs/en-us/sa/developer/all/sa-hosted/secure-acceptance/` وتعمل.
- **الروابط الفرعية** التي تم فتحها (Creating Profile، Payment Method Configuration، Security Keys، Sample JSP، Test and View، Types of Notifications، Testing Credit Card Services) تعمل ومحتواها متوافق مع خطوات التفعيل والكود.
- **تنفيذ المشروع** (endpoint، توقيع HMAC-SHA256، التحقق من الإشعار، الحقول الموقّعة، sale، locale، notify) مطابق للتوثيق المُتحقق منه.
